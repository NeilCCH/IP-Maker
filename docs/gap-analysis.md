# 展示版 vs 規格：差距盤點與本次處理

對照 `docs/handoff-spec.md`。「本次」指第一個里程碑完成的內容。

## 展示版（legacy/demo-v3）找到的問題

| # | 問題 | 本次處理 |
|---|---|---|
| 1 | 新使用者預設帶入「認識衡遠」入口與「衡量當下，規劃長遠」標語 | 已修正：預設入口改為通用服務，標語留白；衡遠改為「進階工具 → 載入範例」 |
| 2 | 品牌名稱提案固定為衡遠、遠見有序、明晰未來 | 已修正：依命名方向、專長、特質產生 3 個提案，可「換一批」；另有標語提案 |
| 3 | 雙頁選單圖只下載目前頁 | 已修正：每頁各自產出上傳圖與點擊區對照圖，素材包一次全部打包 |
| 4 | 標語存在「品牌名稱」題的補充欄 | 已修正：拆到 `identity.slogan`，舊資料遷移時自動搬移 |
| 5 | 「避免事項」只保存不生效；選項為「金色與米白」 | 已修正：禁忌轉為設計旗標，影響配色可選範圍、光效、留白、文案用語與提示詞；選項依規格拆分 |
| 6 | 程式壓縮成單行，難以維護 | 已重寫為模組化原生 ES modules |
